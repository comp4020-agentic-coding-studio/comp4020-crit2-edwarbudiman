# Inari Restaurant Website Redesign --- Project Description

**Status:** Working draft\
**Purpose:** Design brief for review before implementation

## 1. Project Overview

This project will redesign the existing Inari Restaurant website while
preserving the restaurant's established brand identity and existing
customer-facing functions.

The goal is **not to rebrand Inari**. The goal is to create a stronger
digital expression of the existing Inari brand.

The new website should feel recognisably Inari through its logo, kitsune
identity, typography, colour system, photography, spacing, and balance
between refinement and playfulness. At the same time, the website should
improve how customers discover the restaurant, explore the food,
understand functions and events, and reach the booking flow.

The current website remains an important reference for content and
functionality, but it should not limit the new visual system.

## 2. Project Goals

The redesign should:

-   preserve the existing Inari brand identity;
-   make the brand feel more intentional and distinctive on the web;
-   improve the visual hierarchy of the website;
-   make food and kitchen photography a central part of the experience;
-   make booking a clear primary action;
-   improve menu discovery;
-   improve the presentation of functions and group dining;
-   work well on desktop and mobile;
-   use the available photography efficiently without making the limited
    image library feel repetitive;
-   retain current operational information and external services where
    appropriate;
-   create a maintainable foundation for future menu, promotion,
    photography, and content updates.

## 3. Brand Foundation

The redesign must start from the existing Inari identity.

### 3.1 Logo and Kitsune

The existing Inari logo and kitsune/fox mark are primary brand assets.

The redesign must not replace them with a generic restaurant wordmark or
a newly invented Japanese visual identity.

Where official assets allow it, the website should support suitable logo
treatments for:

-   primary brand presentation;
-   light backgrounds;
-   dark backgrounds or photography;
-   compact navigation;
-   small icon or mark usage.

The exact logo variants must be based on official supplied brand assets.
They must not be reconstructed from screenshots when original files are
available.

### 3.2 Colour

The foundational palette should remain centred on the established Inari
colours:

-   Inari red;
-   black;
-   white.

Additional neutral colours can be introduced only when they support
readability, photography, or the physical restaurant atmosphere without
competing with the established palette.

Exact colour values should be taken from official brand assets or
guidelines before implementation.

### 3.3 Typography

Typography is a major part of the redesign.

The website should use two complementary typographic roles:

**Brand/display typography**\
Used for major headings, short statements, campaign-like moments, and
selected brand expressions. It should visually align with the character
of the Inari logo and existing brand material.

**Functional typography**\
Used for navigation, menu information, opening hours, descriptions,
forms, buttons, and other interface content. It should remain highly
readable.

The design should not introduce generic "Japanese-style" brush fonts or
decorative Asian typography simply to communicate Japanese cuisine.

If the original brand typeface can be identified and licensed for web
use, it should be preferred. If it cannot be used, a compatible
alternative should be selected by comparing its proportions, character,
weight, and overall personality with the existing identity.

### 3.4 Space and Composition

Generous negative space should be treated as part of the visual
identity.

The website should avoid filling every section with cards, text, images,
and controls. Important photographs, statements, and brand marks should
have room to stand on their own.

### 3.5 Brand Character

A useful design principle for the digital experience is:

**Tradition × Rebellion**

This should not become a slogan that must appear on the website. It is a
design principle.

The interface should combine restraint with selected unexpected moments.

Examples:

-   structured grid + unusual image crop;
-   simple navigation + strong red brand moment;
-   restrained body copy + expressive display heading;
-   generous whitespace + oversized typography;
-   careful food photography + less predictable composition.

The result should feel playful and contemporary without becoming
chaotic.

## 4. Photography Strategy

The current photo library is sufficient for the first version of the
redesign if it is curated carefully.

Available photography currently includes:

-   chef and preparation photographs;
-   starters;
-   sashimi;
-   makimono;
-   nigiri;
-   mains;
-   dessert;
-   a small amount of drink/dessert imagery.

The website should not present every photograph with equal importance.

### 4.1 Photography Roles

Images should be assigned specific roles:

**Hero / brand images**\
A small number of the strongest images used at large scale.

**Signature food images**\
Selected dishes used to create appetite and introduce the menu.

**Kitchen / craft images**\
Chef and preparation photography used to show process, people, and
craftsmanship.

**Supporting gallery images**\
Additional sushi, starter, nigiri, and makimono photographs used in
controlled editorial layouts or horizontal galleries.

**Closing images**\
Dessert or atmospheric food photography used near booking or final calls
to action.

### 4.2 Repeated Subjects

Multiple photographs of the same dish should not appear consecutively as
separate gallery items.

Alternative photographs can instead be used for:

-   different responsive crops;
-   detail crops;
-   secondary pages;
-   hover or transition states where appropriate;
-   future content rotation.

This allows the available library to feel larger without misrepresenting
the restaurant.

### 4.3 Authenticity

Real Inari photography should be preferred over generated food
photography.

Artificial imagery should not be used to represent actual menu dishes,
restaurant interiors, staff, or experiences that were not photographed.

## 5. Proposed Information Architecture

The initial website should preserve the important functions of the
existing site.

### Primary navigation

-   Home
-   Menu
-   Functions
-   Book a Table

Supporting links such as contact, Instagram, recruitment, newsletter,
and relevant Tiger Lane information can remain available through
appropriate sections or the footer.

## 6. Homepage Direction

The homepage should work as a curated restaurant experience rather than
a long conventional slideshow.

Proposed structure:

### Hero

A strong chef, preparation, or signature food photograph combined with:

-   Inari branding;
-   a concise brand statement;
-   location context;
-   prominent **Book a Table** action.

### Brand Statement

A spacious section that introduces the restaurant's approach using
concise copy and one strong photograph.

### Selected Dishes

An editorial, asymmetric arrangement of a small number of signature
dishes.

This should create visual variety without displaying the entire image
library.

### Menu Introduction

A visual introduction to key menu areas such as:

-   starters;
-   sushi / sashimi;
-   mains;
-   dessert.

The purpose is to encourage exploration of the full menu rather than
reproduce the complete menu on the homepage.

### Kitchen / Craft

Use the chef photographs to show preparation and craft.

This section should add a human and process-driven dimension to the
website rather than presenting only finished dishes.

### Sushi / Makimono Gallery

The larger collection of makimono and nigiri photographs can support a
controlled horizontal or editorial gallery.

It should be user-controlled rather than dependent on an aggressive
autoplay carousel.

### Functions

A concise introduction to functions, group dining, or private events
with a clear path to the dedicated Functions page.

### Closing Experience

Use one strong dessert, food, or atmospheric image followed by a large
booking call to action.

### Footer

Retain useful operational information such as:

-   address;
-   opening hours;
-   contact;
-   social links;
-   newsletter;
-   relevant Tiger Lane links;
-   recruitment information where required.

## 7. Menu Experience

The menu page should become more useful and visual while remaining easy
to maintain.

It should:

-   introduce the menu with selected photography;
-   provide clear access to current food and drink menus;
-   visually distinguish major menu categories where useful;
-   avoid forcing users through unnecessary animation before reaching
    menu information;
-   remain usable on small mobile screens;
-   allow future menu changes without redesigning the page.

The exact menu data source and whether menus remain external documents,
embedded content, or structured website content will be decided during
implementation planning.

## 8. Functions Experience

The Functions page should communicate that Inari can support group
dining and events without inventing operational details.

It can include:

-   strong venue or food imagery;
-   a concise functions introduction;
-   types of suitable occasions;
-   enquiry contact or existing enquiry flow;
-   function menu/document access if currently available.

Capacity, pricing, packages, minimum spend, or other operational claims
must only be displayed when confirmed by Inari.

## 9. Booking

Booking should remain the primary conversion action.

The redesign should preserve the existing booking provider unless there
is a separate business decision to replace it.

The website should improve access to booking through:

-   a prominent desktop navigation action;
-   an obvious mobile booking action;
-   contextual booking calls to action after important content;
-   a clear final booking section.

The website should not rebuild reservation infrastructure unnecessarily.

## 10. Promotions and Operational Content

Temporary promotions should be separated from permanent page layout.

Where practical, promotions should be represented as configurable
content so they can be activated, changed, or removed without
redesigning the website.

The same principle should apply to information that changes regularly,
such as:

-   opening hours;
-   booking notices;
-   special dining periods;
-   event announcements;
-   menu links.

Regular service hours and special/group availability should be presented
separately when necessary to avoid customer confusion.

## 11. Interaction and Motion

Motion should support the brand rather than become the main attraction.

Suitable behaviours may include:

-   restrained image reveals;
-   controlled text reveals;
-   subtle image scaling;
-   user-controlled horizontal galleries;
-   carefully selected sticky elements;
-   smooth navigation transitions.

Avoid excessive:

-   autoplay sliders;
-   parallax;
-   continuous decorative animation;
-   animation on every section;
-   effects that delay menu or booking access.

Accessibility settings such as reduced-motion preferences must be
respected.

## 12. Responsive Design

The website should be designed mobile-first in terms of usability, even
when the desktop composition is more editorial.

Important mobile requirements include:

-   readable navigation;
-   easy booking access;
-   comfortable touch targets;
-   legible menu content;
-   intentional image crops;
-   controlled page weight and image loading;
-   no desktop composition simply squeezed into a narrow viewport.

## 13. Accessibility and Performance

The redesign should improve the technical quality of the experience.

The implementation should aim for:

-   semantic HTML;
-   keyboard-accessible navigation;
-   visible focus states;
-   sufficient text contrast;
-   meaningful image alternative text;
-   reduced-motion support;
-   responsive images;
-   modern image formats where suitable;
-   lazy loading for non-critical images;
-   minimal layout shift;
-   good mobile performance.

Brand expression should not come at the cost of basic usability.

## 14. Content Integrity

The redesign must distinguish between:

1.  confirmed Inari content;
2.  temporary working copy;
3.  proposed marketing copy.

Unverified details must not be presented as facts.

This applies especially to:

-   menu items and ingredients;
-   prices;
-   function capacity;
-   function packages;
-   opening hours;
-   promotions;
-   staff biographies;
-   sourcing claims;
-   dietary information.

## 15. Initial Success Criteria

The first implementation can be considered successful when:

-   the website is immediately recognisable as Inari;
-   the existing logo and brand system remain central;
-   the design does not resemble a generic Japanese restaurant template;
-   customers can quickly find the menu;
-   customers can quickly book a table;
-   functions information remains accessible;
-   the available photo library feels curated rather than repetitive;
-   desktop and mobile layouts both feel intentional;
-   important existing functionality is preserved;
-   temporary content can be updated without major layout changes;
-   the site provides a clean technical foundation for future content
    and photography.

## 16. Current Scope Boundary

This phase defines the website direction.

It does not yet define:

-   final framework or CMS;
-   component implementation;
-   animation library;
-   deployment architecture;
-   final font files or licensing;
-   final image processing pipeline;
-   analytics implementation;
-   final SEO implementation;
-   booking-provider integration details;
-   content migration procedure.

Those decisions will be addressed in the implementation planning phase
after this brief is reviewed and revised.

## 17. Working Principle

The central principle for the project is:

> **Do not redesign the Inari brand. Redesign how the existing Inari
> brand lives on the web.**

The final website should preserve what makes Inari recognisable while
improving its digital storytelling, usability, maintainability, and
conversion path.
